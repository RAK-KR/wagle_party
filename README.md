# 와글와글 파티 (WAGLE PARTY)

보드판 없이 미니게임만 연달아 하는 파티 게임입니다. 4명이 겨루고, 빈자리는 봇이 채웁니다.

## 한 판의 흐름
1. 캐릭터 선택 (같은 캐릭터 중복 불가, 능력치 차이 없음)
2. 판 수(3 / 6 / 10)와 봇 난이도 선택
3. 매 판 룰렛으로 미니게임을 뽑습니다. 한 바퀴 돌기 전에는 같은 게임이 다시 나오지 않습니다.
4. 규칙을 보고 준비 → 3, 2, 1 → 시작
5. 순위대로 1등 3점, 2등 2점, 3등 1점. 마지막 판은 점수 2배
6. 최종 시상대

## 미니게임 (20개)
| 조작 방식 | 이름 | 규칙 |
|---|---|---|
| 캐릭터 조작 | 무너지는 발판 | 밟은 발판이 떨어짐. 끝까지 살아남기 |
| 캐릭터 조작 | 코인 줍기 | 떨어지는 코인 줍기. 폭탄 피하기, 돌진으로 상대 코인 떨어뜨리기 |
| 캐릭터 조작 | 레이저 줄넘기 | 낮은 레이저는 점프, 높은 레이저는 숙이기. 마지막 생존 |
| 캐릭터 조작 | 왕관 차지 | 왕관을 오래 갖고 있기. 닿으면 빼앗김 |
| 탈것 | 범퍼카 링 아웃 | 좁아지는 경기장에서 서로 밀어 떨어뜨리기 |
| 탈것 | 미니 카트 | 3바퀴 먼저 돌기. 잔디는 느려짐 |
| 탈것 | 열기구 별 모으기 | 누르면 상승, 떼면 하강. 별 모으고 새 피하기 |
| 마우스 / 터치 | 풍선 팡팡 | 풍선 먼저 클릭. 금색 +3, 폭탄 -3 |
| 마우스 / 터치 | 같은 얼굴 찾기 | 캐릭터와 표정이 같은 칸 먼저 찾기 (7번) |
| 마우스 / 터치 | 숫자 순서대로 | 1~20을 순서대로 누르기 |
| 타이밍 | 딱 맞춰 멈춰 | 사라진 시계를 속으로 세서 목표 시간에 멈추기 (3번) |
| 타이밍 | 술래 몰래 | 술래가 뒤돌았을 때만 달리기. 들키면 뒤로 밀려남 |
| 타이밍 | 박자 맞추기 | 드럼 노트를 선에 맞춰 치기 (멜로디 없이 드럼만) |
| 타이밍 | 탑 쌓기 | 움직이는 블록을 떨어뜨려 높이 쌓기 |
| 기억 / 관찰 | 몇 번 지나갔지? | 퍼레이드에서 특정 캐릭터가 지나간 횟수 맞히기 (3문제) |
| 기억 / 관찰 | 순서 기억 | 불이 켜지는 순서를 똑같이 누르기. 틀리면 탈락 |
| 기억 / 관찰 | 컵 섞기 | 별이 든 컵 따라가서 고르기 (5번) |
| 물리 | 인간 대포 | 각도와 힘을 정해 과녁에 착지 (3발) |
| 물리 · 팀전 | 줄다리기 (2:2) | 박자에 맞춰 당기기. 이긴 팀 2명이 공동 1등 |
| 물리 | 컬링 | 돌을 밀어 과녁 가운데에 가깝게. 남의 돌 쳐내기 가능 |

한 경기 안에서는 같은 미니게임이 다시 나오지 않고, 같은 조작 방식이 연달아 나오지 않게 순서를 섞습니다.

## 조작
| 동작 | 키 |
|---|---|
| 이동 | WASD / 방향키 |
| 액션 (점프, 부스트, 멈추기, 결정) | Space |
| 감정 표현 | G 누른 채 방향 고르고 떼기 (짧게 누르면 휠이 열린 채로 남고 클릭으로 고름) |
| 조작법 계속 보기 | H |
| 메뉴 | Esc |
| 소리 | M |

휴대폰은 가로 화면에서 왼쪽 스틱, 오른쪽 액션 버튼, 감정 버튼, 왼쪽 위 메뉴 버튼을 씁니다.

## 파일 구조
```
index.html
css/style.css
js/main.js              시작, 화면 크기, 메인 루프, 캐릭터 그리기 연결
js/config.js            상수 (점수, 판 수, 난이도, 색)
js/characters.js        캐릭터 6종 정보와 그림
js/emotes.js            감정 표현 휠과 말풍선
js/input.js             키보드, 마우스, 터치
js/audio.js             효과음, 배경음 (Web Audio로 직접 합성)
js/ui.js                글자, 버튼 등 화면 도구
js/rng.js               시드 난수
js/scenes/menu.js       타이틀, 캐릭터 선택, 연습 목록
js/scenes/match.js      룰렛, 규칙 안내, 진행, 결과, 순위, 시상대
js/minigames/index.js   미니게임 목록 (새 미니게임은 여기에 추가)
js/minigames/common.js  미니게임 공용 도구 (4분할 화면, 별, 코인 그리기 등)
js/minigames/*.js       미니게임 1개 = 파일 1개
```

## 테스트용 주소 옵션
- `?auto=1` 내 캐릭터도 봇이 대신 플레이 (전체 흐름 자동 확인용)
- `?speed=4` 4배속
